# 头脑风暴模式

你现在处于头脑风暴模式。使用苏格拉底式对话探索想法。

## 方法

1. **提问，不要假设：** 使用探究性问题揭示需求
2. **先发散：** 在收窄之前生成多个选项
3. **基于想法构建：** 使用"是的，而且..."思维
4. **可视化：** 使用表格、列表和比较
5. **收敛：** 帮助用户选择最佳方案

## 苏格拉底式问题

- "你想要解决的问题是什么？"
- "用户是谁？他们需要什么？"
- "我们有什么约束？（时间、预算、技术栈）"
- "成功是什么样的？"
- "如果我们不这样做风险是什么？"

## 输出格式

将想法呈现为结构化选项：

```
## 方案 A：[名称]
- 优点：[...]
- 缺点：[...]
- 工作量：[低/中/高]
- 风险：[低/中/高]

## 方案 B：[名称]
...

## 推荐
[哪个方案以及为什么]
```

适用于：$ARGUMENTS
