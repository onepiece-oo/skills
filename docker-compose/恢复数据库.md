### MySQL 8.0 部署

#### 1. 创建项目目录

```bash
mkdir /mysql-compose
cd /mysql-compose
```

#### 2. `docker-compose.yml` 文件内容

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: mysql8
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: "Zhy26825.+8"
      MYSQL_ROOT_HOST: "localhost"
    ports:
      - "33066:3306"
    volumes:
      - ./mysql-data:/var/lib/mysql
      - ./mysql-conf:/etc/mysql/conf.d
    command: [
      "--default-authentication-plugin=caching_sha2_password", # <-- 修改为新的认证插件
      "--bind-address=0.0.0.0"
    ]
```

#### 3. 启动服务

```bash
docker compose up -d
```

#### 4. 进入 MySQL 容器

```bash
docker exec -it mysql8 mysql -uroot -proot
```

#### 5. 恢复数据库

```bash

docker exec -i -e MYSQL_PWD=root mysql8 mysql -u root < all_databases_backup.sql
```

### Redis 7.0 部署

#### 1. 创建项目目录

```bash
mkdir /redis-compose 
cd /redis-compose 
```

#### 2. `docker-compose.yml` 文件内容

```yaml
version: '3'
services:
  redis:
    image: redis:7.0
    container_name: redis7
    restart: always
    ports:
      - "6379:6379"
    volumes:
      - ./redis-data:/data
      - ./redis.conf:/usr/local/etc/redis/redis.conf
    command: ["redis-server", "/usr/local/etc/redis/redis.conf"]
```

#### 3. `redis.conf` 配置文件内容

```conf
# Redis 配置文件
bind 0.0.0.0
port 6379
protected-mode no
appendonly yes
# 请务必修改为强密码
requirepass redis
```

#### 4. 启动服务

```bash
docker compose up -d
```

#### 5. 进入容器

```bash
docker exec -it -w / redis7 bash
```

### Nginx 部署

#### 1. 创建项目目录

```bash
mkdir  /nginx-compose
mkdir  /nginx-compose/html
mkdir  /nginx-compose/nginx-conf
vim nginx.conf
cd /nginx-compose
```

#### 2. `docker-compose.yml` 文件内容

```yaml
# version: "3.8" # 新版 Docker Compose CLI 可以忽略此行，或者干脆去掉
services:
  nginx:
    image: nginx:alpine
    container_name: my-nginx
    restart: always
    ports:
      - "80:80"
    volumes:
      # 路径是相对于 docker-compose.yml 文件所在的目录
      - ./nginx-conf/nginx.conf:/etc/nginx/nginx.conf:ro
      - ./html:/usr/share/nginx/html:ro
    # networks:
    #   - web-network # 先注释掉自定义网络，使用默认网络

# networks: # 如果要使用自定义网络，取消上面的注释，并取消下面的注释
#   web-network:
#     driver: bridge
```

#### 3.conf文件内容

```bash
# 定义 Nginx 运行的工作进程数，auto 表示根据 CPU 核心数自动调整
worker_processes auto;

# 定义全局错误日志级别
error_log /var/log/nginx/error.log warn;

# 定义 PID 文件位置
pid /var/run/nginx.pid;

# 定义工作进程打开文件描述符的数量上限
worker_rlimit_nofile 65535;

events {
    # 每个工作进程并发处理连接的最大数量
    worker_connections 1024;
}

http {
    # 包含 MIME 类型定义文件
    include /etc/nginx/mime.types;
    # 默认 MIME 类型
    default_type application/octet-stream;

    # 定义访问日志格式
    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for"';

    # 定义访问日志路径和格式
    access_log /var/log/nginx/access.log main;

    # 开启高效文件传输模式
    sendfile on;

    # 启用 TCP_NOPUSH，与 sendfile 一起使用，优化性能
    tcp_nopush on;

    # 启用 TCP_NODELAY，优化小数据包传输
    tcp_nodelay on;

    # 客户端请求体大小限制
    client_max_body_size 1M;

    # 客户端请求头缓冲区大小
    client_header_buffer_size 1k;

    # 默认请求缓冲区大小
    large_client_header_buffers 4 4k;

    # 开启 gzip 压缩
    gzip on;

    # 定义虚拟主机服务器块
    server {
        # 监听 80 端口
        listen 80;

        # 定义服务器名称，可以是域名或 IP
        server_name _; # _ 表示匹配任何域名/IP

        # 定义网站根目录（与 docker-compose.yml 中挂载的目录对应）
        location / {
            root /usr/share/nginx/html;
            index index.html index.htm; # 指定默认首页文件名
            # 修改了这一行，使其支持无 .html 后缀访问
            # $uri: 尝试匹配原始请求路径 (例如 /love)
            # $uri/: 尝试匹配路径加斜杠 (例如 /love/)
            # $uri.html: 尝试匹配路径加 .html 后缀 (例如 /love.html)
            # =404: 如果以上都失败，则返回 404 错误
            try_files $uri $uri/ $uri.html =404;
        }

        # (可选) 定义错误页面
        error_page 404 /404.html;
        error_page 500 502 503 504 /50x.html;
        location = /50x.html {
            root /usr/share/nginx/html;
        }
    }
}
```

## 4. Ubuntu 安装 VMware Tools 指南

> **推荐优先使用 `open-vm-tools`（方式一）**，它是 VMware 官方支持的开源实现，无需手动挂载 ISO，自动更新，兼容性好。

### ✅ 方式一：使用 `open-vm-tools`（推荐 ⭐）

适用于绝大多数桌面/服务器场景，**无需手动操作 ISO 镜像**。

#### 步骤如下：

```bash
# 1. 更新系统软件包列表
sudo apt update

# 2. 升级已安装的软件包（可选但推荐）
sudo apt upgrade -y

# 3. 安装 open-vm-tools 及桌面增强功能（如自动调整分辨率、拖拽、剪贴板共享等）
sudo apt install open-vm-tools open-vm-tools-desktop -y

# 4. 重启虚拟机使功能生效
sudo reboot
```

#### ✅ 安装后验证功能：

- **窗口自适应分辨率**：拖动虚拟机窗口大小，Ubuntu 桌面自动调整。
- **双向复制粘贴**：宿主机 ↔ 虚拟机之间可复制文本。
- **文件拖拽**：从 Windows 拖文件到 Ubuntu 桌面（需 VMware 启用该功能）。

> 💡 注意：若使用 **无图形界面的 Ubuntu Server**，只需安装 `open-vm-tools`，无需 `open-vm-tools-desktop`。

### 🔧 方式二：手动安装官方 VMware Tools（仅特殊需求使用）

> ⚠️ 仅在以下情况使用：
>
> - `open-vm-tools` 功能异常
> - 使用非常旧的 VMware 版本（< Workstation 12）
> - 需要特定驱动或调试

#### 步骤如下：

1. **在 VMware 菜单中挂载 Tools 镜像**

   > **虚拟机 → 安装 VMware Tools**
   > （如果提示已挂载，忽略即可）

2. **打开终端，进入挂载目录**

   ```bash
   cd /media/$USER/"VMware Tools"
   ls
   ```

   应看到类似文件：

   ```
   VMwareTools-10.3.23-16594550.tar.gz  manifest.txt
   ```

3. **解压安装包到 `/tmp`**

   ```bash
   cp VMwareTools-*.tar.gz /tmp/
   cd /tmp
   tar -zxvf VMwareTools-*.tar.gz
   ```

4. **运行安装脚本**

   ```bash
   cd vmware-tools-distrib
   sudo ./vmware-install.pl
   ```

5. **重启生效**

   ```bash
   sudo reboot
   ```
